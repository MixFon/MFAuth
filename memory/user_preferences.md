**Why:** Пользователь явно обозначил свои предпочтения в начале проекта.

**How to apply:** Соблюдать при написании любого нового кода в этом проекте.

## Предпочтения

- Использовать встроенные возможности Go по максимуму — никаких фреймворков
- HTTP: только `net/http` и стандартный `ServeMux`
- Сторонние зависимости только там, где без них принципиально нельзя (драйвер БД, bcrypt)
- Комментарии в коде обязательны — пользователь явно попросил объяснять что делает код и какова его цель
- Пользователь вдумчиво изучает код: перед каждым новым шагом просит объяснение что будет реализовано
